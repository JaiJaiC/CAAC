00先想明白：这套题到底在考什么

如果你只记住一句话，请记住这句：考官用文字描述一张图，你要把这张图在软件里还原出来。

0.1 一张航线图，只需要四件事就唯一确定

①
形状
几条边、每条边多长、每个角多大。例："等边三角形，边长 80 米""直角梯形，∠2=135°"。
②
朝向
这张图在地图上怎么摆。例："3 到 1 的指向角 160°""2-3 逆风""∠H12=30°"。
③
起飞点 H
H 相对图里某个点的方位和距离。例："起飞点到 2 点航向 NE，距离 80 米"。
④
位置
某个点的经纬度。例："H 经纬度 N31.26°、E95°20′24″"。

再加上第五样——参数（高度、水平速度、垂直速度、停留时间、转弯模式、循环次数、完成动作）。四件事 + 参数齐了，这张图就唯一确定，答案就没有争议。

为什么这样理解就能举一反三？因为出题人无论怎么改，也只能在"四件事"上换说法：想考几何，就改①；想考你的方位感，就改②；想考你会不会取反方向，就改③；想考你会不会用平移，就改④。你练的是把话翻译成这四件事的能力，而不是背第 37 题的答案。

01能力①：方位角（不会这个，后面全废）

这一节要练到看到数字就能在脑子里转。目标：任意两条边说方位角，5 秒内答出。

1.1 定义与归一化

从正北开始，顺时针转到目标方向的水平夹角，范围 0°~360°。

算出大于 360
一直减 360
400° → 40°　｜　725° → 5°
算出小于 0
一直加 360
−25° → 335°　｜　−190° → 170°
为什么必须归一化：软件输入框、考官口述、图上标注都只认 0~360。你写 −25 或 400，机器和人都不会认。

1.2 顺加逆减：所有"偏"字都靠这条

在某个方向上顺时针再转 → 加；逆时针再转 → 减。

说法算法结果判断依据
东偏南 20°90 + 20110°东 → 南 是顺时针
东偏北 20°90 − 2070°东 → 北 是逆时针
西偏北 20°270 + 20290°西 → 北 是顺时针
西偏南 20°270 − 20250°西 → 南 是逆时针
南偏东 25°180 − 25155°南 → 东 是逆时针
南偏西 25°180 + 25205°南 → 西 是顺时针
北偏东 15°0 + 1515°北 → 东 是顺时针
北偏西 15°360 − 15345°北 → 西 是逆时针
为什么：方位角顺时针增大，所以"往右（顺时针）偏"就是加，"往左偏"就是减。别背表格，记这句。

1.3 反方向（用得最多的一条）

原方向 < 180° → 反方向 = 原 + 180°　｜　原方向 > 180° → 反方向 = 原 − 180°

1-2 = 90° → 2-1 = 270°；3-2 = 290° → 2-3 = 110°。

什么时候用：① 题目给"起飞点到 X 点"的方向，你要填的是 "X-H"；② 题给 3-1，你要用 1-3 去旋转；③ 已知 H-1 要算 1-H。看不见的反方向，就是最容易丢分的地方。

1.4 "到" 与 "在 / 位于 / 相对于"

必错点"A 到 B" → 写 A-B（起点在前）。"A 在 / 位于 / 相对于 B" → 写 B-A（后面那个点在前）。
题面写成为什么
1 点到 2 点的航向为东偏南 15°1-2 = 105°"到" → 前点在前
2 点在 3 点的西偏北 20°3-2 = 290°"在" → 后点在前
H 点（起飞点）位于 4 点 SE 偏 E 10°4-H = 125°从 4 点看 H
5 点相对于 6 点的方位角为 NW 偏 W 5°6-5 = 310°从 6 点看 5 点
一句话理解：方位角是"从谁身上看向谁"。句子里"看"的那个人，就是连线前面的那个点。

1.5 方位词速查

八方位：北 0 · 东北 45 · 东 90 · 东南 135 · 南 180 · 西南 225 · 西 270 · 西北 315

十六方位（每档 22.5°）：N 0 · NNE 22.5 · NE 45 · ENE 67.5 · E 90 · ESE 112.5 · SE 135 · SSE 157.5 · S 180 · SSW 202.5 · SW 225 · WSW 247.5 · W 270 · WNW 292.5 · NW 315 · NNW 337.5

1.6 夹角：题目最爱考的一种"转弯"

本质：∠HAB 是同一顶点 A 上两条射线的差——一条是 A-H，一条是 A-B。已知一条，求另一条。

待求 = 已知 ± 夹角　（从已知边转到待求边是顺时针用 +，逆时针用 −）
  • 题给的是 B-A 或 H-A，先算反方向得到 A-B / A-H。
  • 夹角不会超过 180°；算出比 180° 大，说明符号取反了。
例2-H = 135°，从 2-H 转到 2-3 是顺时针 110° → 2-3 = 135 + 110 = 245°。

1.7 顺 / 逆时针怎么判

至少 3 个航点才有顺逆。做法：把 1→2 延长出去画个箭头，看 3 号点在箭头的左边还是右边。

3 点在左侧
逆时针
画图时夹角输入负数；转折角用"减"
3 点在右侧
顺时针
画图时夹角输入正数；转折角用"加"
为什么顺逆这么重要：它决定两件事——① 夹角法画图时的正负号；② 用一条已知边推其余所有边时是加还是减。顺逆搞反，整张图镜像。

1.8 现在就练（10 秒一题，答案折叠在下面）

  1. 东偏北 35° = ?
  2. 西南偏南 10° = ?
  3. 1-2 = 200°，2-1 = ?
  4. 4 点在 3 点正西，写 3-4 还是 4-3？等于多少？
  5. H-3 = 60°，起飞点要填的第 3 个航点角度是 3-H = ?
看答案
① 90−35 = 55°　② 西南 225，往南（180）是逆时针 → 225−10 = 215°（也可读作南偏西 35+? 直接用减法即可）　③ 200+180 = 380−360 = 20°　④ 写 3-4，"在"后面那个点在前 = 270°　⑤ 60+180 = 240°

02能力②：几何——把文字变成边和角

软件不会替你想几何。你唯一要做的，是把"内角"翻译成"下一段的方位角"，然后交给编辑器生成。

2.1 一条公式，解决所有闭合图形

沿航线前进，过一个顶点：顺时针 → 下一段 = 本段 + (180° − 内角)
逆时针 → 下一段 = 本段 − (180° − 内角)

把 180° − 内角 叫"转折角"。它是方位角每过一个顶点变化多少。

图形内角转折角已知一条边后的走向（顺时针）
等边三角形60°120°30 → 150 → 270 → 30（每段 +120）
正方形90°90°30 → 120 → 210 → 300
正六边形120°60°30 → 90 → 150 → 210 → 270 → 330
正五边形108°72°30 → 102 → 174 → 246 → 318
为什么：方位角顺时针增大。你顺时针绕图形走，每到一个顶点就要把"方向盘"往右打 180°−内角，所以是加；逆时针走就是往左打，用减。内角越大，转折越小——六边形（120°）每段只转 60°，三角形（60°）每段要转 120°，符合直觉。

2.2 内角不用记，会算就行

内角和 = (N − 2) × 180°　→　每个内角 = (N − 2) × 180° ÷ N
边数345681012
内角6090108120135144150
转折角120907260453630

正多边形还有一条好用的性质：转折角 = 360° ÷ N。六边形 60°、八边形 45°，一眼可得。

2.3 三个必须熟练的特殊图形

正方形
转折 90°
边长相等；对角线 = 边长 × 1.414；"正方形变蝴蝶"靠交换两个航点。
等腰直角三角形
90° / 45° / 45°
转折依次 90°、135°、135°；斜边 = 直角边 × 1.414。
直角梯形
两个 90° + 一个 135°
先找两条平行边；135° 处转折 45°，于是那段是 45° 斜边、水平位移 = 垂直高度。
梯形怎么想：题目说"直角梯形，1-4 = 75 米，∠2 = 135°"，其实是在告诉你：左侧竖边 75 米、右下角被"切掉"了 45°，所以那条斜边一定是 45° 方向、水平位移也是 75 米。顶边长度 = 底边 + 75。整道题的几何在这一步就解完了。看到 135° 就想 45°，看到 120° 就想 60°，看到 150° 就想 30°。

2.4 算边长：先判断用哪把"刀"

已知用什么公式
两条直角边勾股定理c = √(a² + b²)；3-4-5、6-8-10、5-12-13 直接认
45° 直角三角形等腰直角斜边 = 直角边 × 1.414；两腰相等
30° / 60°特殊角三边比 1 : √3 : 2（短边 × 1.732 = 长直角边）
两边 + 一个对角（求方位或第三边）正弦定理a / sinA = b / sinB = c / sinC
两边 + 夹角（求第三边）余弦定理c² = a² + b² − 2ab·cosC
H 到两点的距离 + 夹角（求 H 到第三点）正弦定理先画三角形，再 sin 出那个角，最后加减到方位角上
心算直角边相等时斜边 ≈ 边 × 1.414：30 → 42.4；75 → 106.1；100 → 141.4；200 → 282.8。这几个数背下来，梯形题能省 30 秒。

2.5 时钟题：只是另一种方位角

时针 = 30°×H + 0.5°×M　｜　分针 = 6°×M　｜　夹角 = |分针 − 时针|（> 180° 用 360° 减）
  • 时针 60 分钟走 30°，所以 0.5°/分；分针 60 分钟走 360°，所以 6°/分。
  • 题说"航向 / 方向为 X 点 Y 分" → 取时针位置 30X + 0.5Y。
  • 题说"X 点 Y 分时针与分针的夹角" → 先算夹角，再当夹角条件用。
为什么时针要加 0.5M：时针不是"整点才动"，它一直在慢慢走。1:48 时时针已经走过 48 分钟，多转了 24°，所以是 30+24 = 54°，而不是 30°。忘了这 0.5，答案就错 24°。

2.6 图上带坐标轴怎么办

把"图上的上下左右"翻译成"东南西北"：图上向上 = 北 = 0°，然后按箭头方向数过去。例如图上 X 轴向上、Y 轴向右，则沿 X 正方向 = 0°，沿 Y 正方向 = 90°，反向各 +180°。

2.7 小练习

  1. 正八边形，内角多少？顺时针每段加多少？
  2. 等腰直角三角形，直角边 200 米，斜边多少？
  3. 直角梯形上底 275、下底 200、高 75，斜腰（右下）方位角多少度、多长？
看答案
① 内角 135°，转折 45°。② 200 × 1.414 = 282.8 米。③ 45°（水平位移 75 = 高度 75），长度 75 × 1.414 = 106.1 米。

03能力③：软件四步法（画 → 转 → 摆 → 移）

软件只用四步。难点不在按钮，而在为什么必须是这个顺序。

3.1 四步与顺序的道理

  1. 画：先随便放一个 H、一个 1 号点，用相对坐标编辑器把图形画闭合。形状对就行，摆在哪里、朝哪个方向都无所谓。
  2. 转：算出题里那条"被固定的边"的真实方位角，用旋转工具把整张图转过去。转完之后，图上的方位角才是真的。
  3. 摆：用"起飞点位于第 N 个航点 + 距离 + 角度"把 H 摆到位。填的一定是 N-H 的方位角。
  4. 移：用平移工具把图整体挪到真实经纬度。H 会跟着一起挪，相对关系不变。
顺序铁律必须先转、后摆。因为在没旋转的图上，1-2 的方位角是"假"的（随便给的），你却用真实方位去摆 H，H 一定偏。这就是最常见的整题崩盘原因。
为什么平移放在最后：平移只改变"绝对位置"，不改变"相对关系"。所以你可以先在某处把形状、朝向、H 都调完美，最后一键搬到真实坐标，一次成功。

3.2 每一步：点哪里 + 怎么算做对

步骤操作做对的判断标准
画相对坐标编辑器：基准点 / 插入序号 → 方位角 + 距离 → 生成；或切夹角模式填内角（逆时针填负数）反复生成至闭合最后一个点与 1 号点重合、图上每段都显示正确的长度
转旋转工具 → 输入那条已知边的方位角 → 确认用测距工具量这条边，方位角 = 题给值
摆选中 H → 起飞点位于图形的第 N 个航点 + 距离 + 角度量 N-H 的方位角与距离，与换算结果一致
移平移工具：基准点 + 纬度 + 经度 → 平移该点经纬度与题卡完全一致（注意秒）
参数左侧面板逐点改；整条航线用航线设置绿色执行航点列表里逐条核对无误
交卷上传 → 设开始执行点考官看你的屏幕能对上题卡

3.3 参数分三类，别混

整条航线
航线设置
整体高度、航点速度、循环次数、转弯模式、完成动作。题说"整体 / 所有航点"就用它。
分段
逐点改
"1、2、3 点高度 80，4、5、6 点高度 50"。
单点
逐点改
"4 点为停止转弯，其余协调转弯"。
三个必查① 水平、垂直速度两个都要改；② "起飞点高度为航线高度"要把 H 也改；③ 协调转弯时停留时间无效（停止转弯 = 定点转弯 = 悬停，是同一个东西）。

3.4 五个必须会的小操作

  • 距离 0 插点：以某点为基准、任意角度、0 米插入，可造出"和上一点重合的点"，用来做蝴蝶形、或让 H 临时借一个点。
  • 右键【向后添加】/【删除航点】：加中间点、删点、把 3 号变成 4 号，全在这。
  • 反序工具：图形顺逆画反了，一键改过来，不用重画。
  • 测距工具：量任意两点的方位角与距离——你的"验算器"。
  • 坐标开关：打开后新点按经纬度插入（双坐标题要用），用完立刻关，否则后面的点全部重合。

3.5 60 秒自检

量三段：题给的那条固定边（验朝向）、N-H（验起飞点）、最长的一条边（验比例）。三段都对，再上传。

04能力④：条件翻译（举一反三的核心）

题面写法可以无穷多，但归宿只有三条线：朝向、H、位置。见到任何一句条件，先问自己"它在说四件事里的哪一件？"

A
它影响"朝向"
→ 你要得到某一条边的方位角，然后用旋转工具。
B
它影响"H 的位置"
→ 你要得到 N-H 的方位角 + 距离，然后填起飞点快捷调整。
C
它影响"绝对位置"
→ 你要用某点的经纬度做平移。
D
它在说"参数"
→ 照抄进左侧面板 / 航线设置，注意单位与作用范围。

4.1 朝向类：本质只有三种

题面写法本质你做什么
"3 到 1 的指向角 160°"直接给方位3-1 = 160，要用时取 1-3 = 340
"4 点在 3 点 NE 方向 140 米"直接给方位3-4 = 45，顺带核对边长 140
"1 到 2 的航向为北偏东 30°"直接给方位1-2 = 30，直接用它画第一条边
"∠H12 = 30°（起飞点在图形内侧）"给角度关系先求 H-1，再 1-2 = 1-H ± 30（内外侧决定正负）
"∠H12=30°，∠H14=120°"给角度关系两条射线交会，先算 1-H，再反求 1-2
"2-3 与 H-1 航向相同 / 相反（相向）"给角度关系相同 2-3 = H-1；相反 ±180
"西北风，2-3 逆风 / 5 到 4 正右侧风"给角度关系用风向四式把风翻成边的方位角（见下）
"航向为 1 点 48 分（时针）"给角度关系30×1 + 0.5×48 = 54
"H 到 5、6 距离相等且等于边长"图形理解H 是正六边形中心 → 1-H = 内角平分线，距离 = 边长
"A、B 两点经纬度"坐标画出 A、B，读 A-B 的方位角，就不用旋转了
图上带 X / Y 坐标轴坐标把轴方向换算成北向，读出某边方位角

风向：一条口诀，四种情况

风向 F 是风的来向。顺风 = F+180　｜　逆风 = F　｜　左侧风 = F+90　｜　右侧风 = F−90
本场风向 F顺风逆风左侧风右侧风
西北风（F=315）13531545225
西南风（F=225）45225315135
东南风（F=135）31513522545
东北风（F=45）22545135315
为什么顺风是 F+180："西北风"是从西北吹过来的风，它把飞机往东南推。所以飞机往东南飞才是顺风，而东南 = 315+180 = 135。左侧风/右侧风则是相对机头左右各 90°。先想清楚"风往哪吹"，再套式子。

4.2 起飞点类：全部化成"N-H 方位角 + 距离"

题面写法类型换算
"起飞点到 X 点航向 SW，距离 80 米"要反转题给 H-X = 225，填 X-H = 45，80 米
"起飞点位于 X 点西偏北 20°，200 米"直接用X-H = 290，200 米
"∠H12 = 30°，距 1 点 75 米"交会1-H = 1-2 ± 30，75 米
"H 到 1、2 两点距离相等"交会H 在 1-2 中垂线上：中点 + 1-2 ± 90，距离 √(D² − (L/2)²)
"起飞点垂直于 1-2 边中点，距 100 米"交会中点 + 1-2 ± 90，朝图形外侧
"起飞点在 1-2 延长线上，距 1 点 150 米"交会方位同 1-2，距离 150（不是反方向！）
"另给 H 经纬度"（双坐标）坐标选中 H 输经纬度 → 回车（别点确认按钮）
"起飞点与考试席位方位由委任代表现场决定"口述按考官现场说的方位与距离填，先随便放
为什么"到 X 点"必须反转：软件那个框问的是"从第 N 个航点看 H，在什么方向"，也就是 N-H。题里写的是"从 H 看 X"，方向正好差 180°。这就是为什么同样的数字，有人填进去 H 跑到了图形另一侧。

4.3 位置类：两种，外加一个坑

  • 单点：题给一个点的经纬度（多数是 H，也可能是某个航点）→ 平移工具，基准点选它。
  • 双点：H + 某航点（直接输 H 坐标），或两个航点（用坐标开关画出一条已知边，免旋转）。
  • 坑：题卡写"1 号点经纬度"，但你前面插了避让点，1 号已经变成 2 号——平移基准点要跟着改。

4.4 参数类：三步解码

很多新题把数字换成字母 a / b / c…，字母每张卡都不一样。

  1. 在(一)里把每个字母和它修饰的名词连起来："边长为 a""高度为 b""水平速度为 c"。
  2. 到(二)里取值，"建议为"也是要填的值。
  3. 按"整条 / 分段 / 单点"三类归位，注意单位（km/h ÷ 3.6 = m/s）。
试一下：这句话说了哪几件？"规划一个手动闭合正六边形并循环执行，边长为 a，123 点相对地面高度为 b，水平速度为 c，转弯方式为停止转弯，各点停留时间为 d"
形状 = 正六边形（6 条边、内角 120°、顺时针）+ 边长 a；参数 = 分段高度（1-3 点 b）、水平速度 c、转弯模式（停止）、停留 d、循环（执行 1 次）。没有提朝向——所以这道题一定另有朝向条件，或者题图本身给了。

05例题精讲：六道题，把方法焊死

每题都按同一个动作套路走：先归位（四件事）→ 再算角 → 再画 → 再摆 → 再平移 → 再填参数 → 最后自检。看懂前两题，后面就是换参数。

例 1等边三角形：最标准的全流程
图形：等边三角形，边长 80 m。题图 1→2→3 为逆时针（题图只告诉你形状和顺逆，真实朝向由下面的角度决定）。
朝向：3 到 1 的指向角度为 160°。
起飞点：起飞点到 2 点航向 NE，距离 80 m。
参数：航高 90 m、水平 3 m/s、垂直 2 m/s；停止转弯，1 点停 3 s、其余 5 s；闭合循环 3 圈。
位置：H 经纬度 N31.26°、E95°20′24″。
第 1 步：归位——这句话在说哪件事
形状等边三角形 80 m → 内角 60°，转折角 120°
朝向3-1 = 160°，要转成 1-3 = 340°
H"起飞点到 2 点 NE" → H-2 = 45° → 要填 2-H = 225°，80 m
位置H 的经纬度，平移基准点就是 H
第 2 步：算三条边（转折公式，逆时针用减）
  1. 题给 3-1 = 160°。
  2. 下一个航段是 1-2：1-2 = 160 − (180−60) = 160 − 120 = 40°。
  3. 再下一段 2-3：40 − 120 = −80 → 280°。
  4. 再下一段 3-1：280 − 120 = 160° —— 又回到题给的值，说明三条边算对了（这就是自检）。
第 3 步：在软件里做
  1. 画：任意点 1 号点 → 相对坐标编辑器 40°、80 m → 生成 2 号点 → 切夹角模式，内角 60、距离 80、负号（逆时针）→ 连点两次生成，第 4 个点落回 1 号点，闭合。
  2. 转：旋转工具让 3-1 = 160°（若工具按 1-2 输入，就填 40°）。
  3. 摆 H：起飞点位于第 2 个航点，距离 80，角度 225。
  4. 移：平移工具基准点 = H，纬度 31.26、经度 95.34（95°20′24″ = 95 + 20/60 + 24/3600 = 95.34）。
  5. 参数：全部航点高度 90、水平 3、垂直 2；1 点悬停 3 s、其余 5 s；循环 3 圈。
答案：1-2 = 40°、2-3 = 280°、3-1 = 160°；起飞点在第 2 个航点 225°、80 m 处；航高 90、水平 3、垂直 2、1 点 3 s 其余 5 s、循环 3 圈。
这题会怎么变形
  • 改成顺时针 → 三条边变成 +120：1-2 = 100、2-3 = 220、3-1 = 340。
  • 改成"2 点在 3 点 SW 方向" → 先写 3-2，再取反得 2-3。
  • H 改成"起飞点位于 2 点 SW 80 m" → 这时不用反转，直接填 2-H = 225。
  • H 改成"到 2 点距离 80 m，在图形外侧" → 光有距离是圆，必须再看图定方向。
例 2正六边形 + 起飞点在中心（图形理解）
图形：正六边形，边长 300 m，1→2→…→6 顺时针。
朝向：1 到 2 的航向为北偏东 30°。
起飞点：H 到 1 点、2 点的距离都是 300 m，且 H 在图形内侧。
参数：1、2、3 点高度 80 m；4、5、6 点高度 50 m；水平 3 m/s、垂直 2 m/s；停止转弯，各点 5 s；闭合不循环，完成后悬停 1 点位置。
位置：本题不给经纬度。
归位

形状 = 六边形（内角 120、转折 60）；朝向 = 1-2 = 30°；H = 图形理解；位置 = 无（不用平移）。

算 + 做
  1. 顺时针每段 +60：30 → 90 → 150 → 210 → 270 → 330 → 30，最后回到起点，闭合 ✓
  2. 画图：1-2 = 30°、300 m；夹角模式内角 120、正号（顺时针）、距离 300 → 连点 5 次生成 6 个点后回到 1 号点。
  3. 摆 H：六边形"中心到顶点距离 = 边长"，所以 H 只能是中心（外侧那个点不符合"内侧"）。
    中心方向 = 内角平分线：1-H = 1-2 + 60 = 90°，距离 300 m。
    核对：1-2 = 30、1-6 = 150，两者中间正好 90°，与"中心"吻合。
  4. 参数：1、2、3 号点填 80；4、5、6 号点填 50；水平 3、垂直 2；停止转弯、各点 5 s；不循环；完成动作 = 悬停 1 点位置。
答案：六条边 30 / 90 / 150 / 210 / 270 / 330；起飞点在第 1 个航点 90°、300 m 处；分段高度 80 / 50。
这题会怎么变形
  • "H 在图形外侧" → 方向改成 1-2 − 60 = 330°，距离仍是 300。
  • "H 到 1、2 距离均为 400 m（大于边长）" → H 在 1-2 的中垂线上，用中垂线法算距离。
  • "H 到 1、2、3 三点距离相等" → 还是中心（三点定圆）。
  • 给你一个经纬度 → 第 5 步加一次平移。
例 3直角梯形 + 双夹角定 H
图形：直角梯形 1-2-3-4（1 左下、2 右下、3 右上、4 左上，逆时针）；1-2 = 200 m、1-4 = 75 m、∠1 = ∠4 = 90°、∠2 = 135°。
朝向：3 到 4 的航向为西（270°）。
起飞点：∠H12 = 30°、∠H14 = 120°，起飞点距离 1 点 75 m。
参数：航高 70 m、水平 4 m/s、垂直 2 m/s；停止转弯，各点 5 s；闭合不循环；起飞点高度为航线高度。
归位 + 算
  1. 朝向：3-4 = 270°。1-2 与 3-4 是两条平行底边、方向相反 → 1-2 = 90°。
  2. ∠2 = 135° → 转折角 45°，逆时针用减 → 2-3 = 90 − 45 = 45°。
  3. 45° 斜边意味着"水平位移 = 竖直落差"。竖直落差就是左侧边 1-4 = 75 m → 2-3 = 75 × 1.414 ≈ 106.1 m，顶边 3-4 = 200 + 75 = 275 m。
  4. ∠4 = 90° → 转折 90° → 4-1 = 270 − 90 = 180°；再验 1-2 = 180 − 90 = 90° ✓ 闭合。
  5. 画图：1-2 = 90°、200 m；夹角 135（逆时针 −）、距离 106.1 → 生成 3；夹角 90（−）、距离 275 → 生成 4 → 回到 1 闭合。
  6. 旋转：让 1-2 = 90°（题给 3-4 = 270，等价）。
  7. H：两个条件同时满足才唯一。
    ∠H12 = 30 → 1-H = 90 ± 30 = 60 或 120；
    ∠H14 = 120 → 1-H = 0 ± 120 = 120 或 240；
    公共解 = 120°。填：起飞点在第 1 个航点，角度 120，距离 75。
  8. 参数：全部 70 m；H 高度也改 70；水平 4、垂直 2；各点 5 s；不循环。
答案：1-2 = 90°、2-3 = 45°（106.1 m）、3-4 = 270°（275 m）、4-1 = 180°（75 m）；起飞点在第 1 个航点 120°、75 m 处。
为什么双夹角一定要"找公共解"：一个夹角条件只给你两条射线（±），两个条件才有交点。考试里如果只用一个，H 会落在镜像位置——考官一眼就能看出来。
这题会怎么变形
  • ∠2 改成 120° → 转折 60°，2-3 变成"斜得更平"，边长用 75 ÷ sin60。
  • 平行关系改成"4 点在 3 点正西" → 等价，还是 3-4 = 270。
  • H 条件换成"∠H21 = 45°、距 2 点 100 m" → 先算 2-1，再 ±45。
例 4等腰直角三角形 + 风向
图形：等腰直角三角形 1-2-3，∠2 = 90°、1-2 = 2-3 = 200 m，1→2→3 顺时针。
朝向：本场西北风，2-3 为逆风。
起飞点：起飞点位于 3 点 SW 方向 100 m。
参数：航高 66 m、水平 2 m/s、垂直 6 m/s；定点转弯，各点 6 s；闭合不循环，完成后悬停 1 点位置。
归位 + 算
  1. 风向：西北风 F = 315°；逆风 = F → 2-3 = 315°。
  2. 顺时针走，每过一个顶点把方位角加上转折角：
    顶点 2 内角 90 → 转折 90：1-2 = 315 − 90 = 225°；
    顶点 3 内角 45 → 转折 135：3-1 = 315 + 135 = 450 → 90°；
    顶点 1 内角 45 → 转折 135：1-2 = 90 + 135 = 225° ✓ 闭合。
  3. 斜边：3-1 = 200 × 1.414 ≈ 282.8 m。
  4. 画图：1-2 = 225°、200 m；夹角模式内角 90、正号（顺时针）、距离 200 → 生成 3；内角 45、正号、距离 282.8 → 回到 1 闭合。
  5. H："起飞点位于 3 点 SW" → 已经是 3-H，不要反转。填：起飞点在第 3 个航点，角度 225，距离 100。
  6. 参数：66 / 2 / 6；定点转弯、各点 6 s；不循环；完成动作 = 悬停 1 点位置。
答案：1-2 = 225°、2-3 = 315°、3-1 = 90°（282.8 m）；起飞点在第 3 个航点 225°、100 m 处。
这题会怎么变形
  • "2-3 顺风" → 2-3 = 135（西北风的顺风方向是东南）。
  • "1-2 为正左侧风" → 1-2 = F + 90 = 45。
  • "3 点位于起飞点 SW" → 这时是 3-H 的反方向，要填 H-3 = 45。
例 5避让点：在 1 号点前面插一个点
图形：正六边形，边长 300 m，1-2 = 30°（顺时针）。
空域限制：起飞后先向 NE 飞 600 m 到达"避让点"，再执行航线；避让点高度 320 m。
图形 1 号点在"避让点" NW 方向 500 m 处。
参数：1、2、3 点高度 80 m；4、5、6 点高度 50 m；水平 3、垂直 2；停止转弯、各点 5 s；闭合不循环。
归位：这道题多了一件事

它的 ①形状②朝向 和例 2 一模一样，只是 ③H 的位置变成了"先经过一个避让点，再到图形"。翻译过来就一句：避让点是你的新 1 号点，图形整体往后挪一位。

算 + 做
  1. 正常画图：六条边 30 / 90 / 150 / 210 / 270 / 330（同例 2），并旋转好。
  2. 反推避让点：题说"图形 1 号点在避让点的 NW"，反过来就是"避让点在图 1 号点的 SE" = 135°、500 m。
    操作：相对坐标编辑器，基准点 = 1 号点，插入点 = 1 号点，方位 135、距离 500 → 生成。新点成为 1 号（避让点），原 1 号变 2 号，后面全部 +1。
  3. 避让点高度：单独改成 320 m。
  4. 摆 H：起飞后向 NE 600 m 到避让点 → 从避让点看 H 是 SW → 填：起飞点在第 1 个航点，角度 225，距离 600。
  5. 参数对应新序号：题卡说"1、2、3 点 80 m" → 你现在是 2、3、4 号点；"4、5、6 点 50 m" → 你现在是 5、6、7 号点。
  6. 平移：如果题给了坐标，且写的是"图形 1 号点"，基准点要选 2 号点。
答案：避让点 = 第 1 个航点（图 1 号点的 135°、500 m 处）；六条边 30…330；起飞点 = 第 1 个航点 225°、600 m；避让点高度 320；图 1-3 点高度 80 → 实际 2-4 点。
这题会怎么变形
  • 两段飞行（"先向 NE 300 m 到障碍点，再向 NW 500 m 到航点 1"）→ 反推两次：先以 1 号为基准 SE 500 得障碍点，再以障碍点为基准摆 H。
  • 题里叫"过渡点""障碍点"→ 和避让点是同一个位置，处理方式一样。
  • 避让点高度写成"h 值为 320 m" → 一样填 320。
例 6字母题（参数化）与扫描航线
6a 六边形参数版：（一）规划一个手动闭合正六边形并循环执行，边长为 a，123 点相对地面高度为 b，456 点相对地面高度为 c，水平速度为 d，垂直速度为 e，转弯方式为停止转弯，各点停留时间为 f。
（二）a 值建议为 300 米，b 值建议为 80 米，c 值建议为 50 米，d 值建议为 3 m/s，e 值建议为 2 m/s，f 值为 5 s。
解码：一条一条对
(一) 里的说法字母(二) 的值填到哪
边长为a300画图距离（每条边 300 m）
123 点相对地面高度b801、2、3 号点高度（选相对地面）
456 点相对地面高度c504、5、6 号点高度
水平速度d3水平速度
垂直速度e2垂直速度（别只填水平）
各点停留时间f5悬停时间
转弯方式：停止转弯——转弯模式（= 定点转弯 = 悬停）
循环执行——循环 1 次（不写次数＝执行一次）
注意这类题只给了形状和参数，没给朝向。所以一定有别的条件（题图、H 条件、或另一条"点到点"）在决定旋转；如果通读全题都没有，就按题图摆放。先找朝向，再动手画。
6b 扫描航线：（一）规划扫描航线要求闭合不循环，航线长度为 a，航线间隔为 b，航线相对地面高度为 c，水平速度为 d，垂直速度为 e，转弯模式为协调转弯。
（二）a 值 500 米，b 值 100 米，c 值 300 m，d 值 3 m/s，e 值 2 m/s。
做
  1. 打开扫描航线工具，逐项填：长度 500、间隔 100、相对地面高度 300、水平 3、垂直 2。
  2. 转弯模式选协调转弯（不停留，停留时间这一项就不起作用了）；闭合、不循环。
  3. 生成后检查：条带方向一致、条带数量与间隔对得上、没有缺条。
  4. 如果同时要求"逆风起降"，起降航向要朝风的来向（F），不是顺风方向。
要点：字母题的难点不是算，是别对错行。养成习惯：拿笔在题卡上把字母圈出来，旁边写软件里的字段名，再抄数值。

06题型全景：八种组合，其实只有一件事在变

几乎每张卡都是下面八种的叠加（比如"正六边形 + 避让点 + 风向 + 字母题"）。练的时候按组合练，考试时按拆解做。

组合题面特征它在换哪件事的说法解法主线
① 正多边形等边三角形 / 正方形 / 正五 / 正六边形，给边长或"总边长"形状内角 → 转折角 → 一条边推全部（顺时针加、逆时针减）
② 梯形 / 四边形直角梯形、任意四边形，给边长 + ∠1∠2∠3形状找平行边定一条边；135°→45°、120°→60°；勾股补边长
③ 图形理解H 到两点等距、H 在中心、垂直于某边中点、平分某个角朝向 或 H先把几何结论翻成一个角度或一条边，再当普通条件用

⑤ 风向"西北风，2-3 逆风""5 到 4 正右侧风""3 位于 2 点正下风"朝向F 是来向：顺 F+180 / 逆 F / 左 F+90 / 右 F−90

⑧ 坐标 / 扫描 / 字母题给两点经纬度；或"规划扫描航线，长度 a、间隔 b…"位置 或 参数双坐标：画线读方位，免旋转；扫描：按 a~f 逐项填；字母题：逐个对表
怎么用它练"举一反三"：每做完一道，问自己三句——① 这题的"形状"是怎么给的？② "朝向"是用哪种方式给的？③ H 是"直接方位""夹角交会"还是"坐标"？把三句答案写下来，你会发现不同题之间的差别，只有"换了一种说法"这一层。

07重规划：只有三类指令，记住"速前高后"

这一关考的不是数学，是听懂、改对、报准。

速度看"前"（起点航点）　｜　高度看"后"（终点航点）　｜　改整段 → 两端都改
为什么：每个航点的参数描述的是"从它出发时的速度"和"到达它时的高度"。所以"2 到 3 速度提 1"是改 2 号点的速度；"2 到 3 高度升 5"是改 3 号点的高度。想通这一点，一整张表都不用背。

7.4 收尾流程与话术

  1. 复述把指令重复一遍——既是核对，也给自己争取操作时间。
  2. 改 → 上传需要从中间开始就设"开始执行点"。
  3. 报告"报告考官，修改完毕，是否执行航线？"
  4. 执行 + 主动汇报"报告考官，飞机正以 3 米每秒的速度飞往 2 号点，当前高度 30 米，当前电压 46.87 伏，卫星颗数 28 颗。"
  5. 盯暂停鼠标提前放到暂停按钮上；考官指定的航点一到就暂停，拿遥控器准备返航。

08应急返航：钟点法定向 + 手飞

"应急返航"= 回起飞点 H。考官会让你手动飞向某个点，考的是不看屏幕也能飞对方向。

8.1 钟点法：一个乘法

目标方位角 = 30° × 钟点数 X

把"飞机当前位置 → 目标点"连一条线，看它指向几点钟，那个"几点"乘 30 就是你要转到的方位角。

钟点123456789101112
方位角3060901201501802102402703003300
为什么是 30：钟面一圈 12 小时对应 360°，一小时 30°。和 1.5 节的十六方位是同一个道理。

8.2 操作顺序

  1. 算 Y目标方位 Y = 30X；再判断从当前机头转到 Y，顺时针近还是逆时针近（差值 ≤180° 那侧更近）。
  2. 切姿态模式考官会遮屏或移屏，不许看屏幕飞。切模式，眼睛看飞机。
  3. 快转 → 提前慢转先快速转；离 Y 还差 30° 开始慢转；差 15° 开始缓慢推前进并继续转到 Y。
  4. 按限速前进考官说"不超过 5 m/s"就压在 5 以内；偏了随时修方向。
  5. 接近减速快到点时减速到 1 m/s，让飞机箭头停在目标点上。
  6. 风大用副翼修有侧风会飘，持续用副翼压住，别让机头偏。
左转 / 右转
顺时针 = 右转，逆时针 = 左转（和方位角增大的方向一致）。
常见扣分
转过（过冲）、速度超限、箭头没停在点上、切错模式。宁可慢转，不要过冲。

天练什么怎么算过关

自测 6 题（先自己算，再展开）

  1. 东偏北 35° 等于多少？
  2. 等边三角形逆时针，已知 3-1 = 160°，求 1-2。
  3. 正六边形顺时针，已知 1-2 = 30°，求 4-5。
  4. 本场西北风，1-2 为正左侧风，求 1-2。
  5. 题说"起飞点到 2 点航向 NE，距离 80 m"，你在起飞点快捷调整里填什么？
  6. 15:40，时针与分针的夹角是多少？
看答案
① 90−35 = 55°。 ② 用转折公式逆时针减 120：160−120 = 40°。 ③ 顺时针每段 +60：30→90→150→210，所以 4-5 = 210°。 ④ 左侧风 = F+90 = 315+90 = 405 → 45°。 ⑤ 第 2 个航点、角度 225、距离 80（因为题给的是 H-2，要取反得 2-H）。 ⑥ 时针 = 30×3 + 0.5×40 = 110°，分针 = 6×40 = 240°，夹角 = 130°。
最后一句题目永远在描述"形状 + 朝向 + H + 位置 + 参数"。你练到看见任何一句话都能立刻归类，就已经能举一反三了——剩下的只是手速。
