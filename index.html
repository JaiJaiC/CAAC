01考试三关

一场考试连续走完三关，全程在 LinkGCS 上操作 + 口述报告。

关卡考官给你什么你要做什么过关标准
①
预规划
核心，占多数时间		 一张题卡：图形 + 边长/内角 + 1 个经纬度 + 高度/速度/停留/循环 + 一条朝向条件 画闭合图形 → 旋转到正确朝向 → 摆好起飞点 → 平移经纬度 → 录全部参数 → 上传 图上方位角、距离、H 位置、经纬度、参数全对
②
重规划		 飞机已在执行航线，考官口述指令（变点 / 变高 / 变速） 复述指令核对 → 改航线 → 上传 → 报告 → 执行 → 主动汇报飞行数据 复述无误，改完的点/高度/速度正确，会报告
③
应急返航		 指定一个航点或返航点，要求速度上限 切姿态模式 → 用钟点法定向 → 手动转 + 推前进 → 到点减速悬停 方位角不过大，速度不超限，箭头停在点上

整场顺序：预规划（审题 1′ → 作答 3′ → 检查 3′）→ 上传执行 → 重规划（变点 / 变高 / 变速）→ 到点暂停 → 应急返航（切姿态手动定向）。

预规划的三段时间（宝典建议）

审题 1′
图形形状、顺/逆时针、1 号点起始位置；参数是全局还是局部。
作答 3′
画图 → 旋转 → 摆 H → 平移 → 输参数。每步点“确认/生成”。
检查 3′
测方位角距离、核经纬度、核绿色执行航点列表。查完才上传。
默认参数考官没要求时用：航高 30 m、水平速度 3 m/s、垂直速度 3 m/s、悬停 3 s。重规划新加的点也必须补成这套值，否则是 0。

02方位角基础（全部题的地基）

这一节不熟，后面所有题型都是猜。花 20 分钟练到 5 秒一个。

2.1 定义与归一化

从正北起，顺时针转到目标方向的水平夹角，范围 0° ~ 360°。

超过 360
一直减 360
如 400° → 40°
小于 0
一直加 360
如 −25° → 335°

2.2 顺加逆减

在原方向上顺时针转 → 加；逆时针转 → 减。

说法算法结果记忆
东偏南 20°90 + 20110°从东往南走是顺时针 → 加
东偏北 20°90 − 2070°从东往北走是逆时针 → 减
西偏北 20°270 + 20290°从西往北是顺时针 → 加
西偏南 20°270 − 20250°从西往南是逆时针 → 减
南偏东 25°180 − 25155°从南往东是逆时针 → 减
南偏西 25°180 + 25205°从南往西是顺时针 → 加
北偏东 15°0 + 1515°从北往东是顺时针 → 加
北偏西 15°360 − 15345°从北往西是逆时针 → 减

口诀：“偏”字看转弯方向——基准方位指向“偏”的那个字，是顺时针就加，是逆时针就减。

2.3 反方向（用得最多）

原方向 < 180° → 反方向 = 原 + 180°　｜　原方向 > 180° → 反方向 = 原 − 180°

例：1-2 = 90°，则 2-1 = 270°；3-2 = 290°，则 2-3 = 110°。

2.4 “到” 与 “在 / 位于 / 相对于”（最高频失分点）

必错点 “A 到 B” → 写 A-B，起点在前。
“A 在 / 位于 / 相对于 B” → 写 B-A，后面那个点在前（从 B 指向 A）。
题面写成为什么
1 点到 2 点的航向为东偏南 15°1-2 = 105°“到” → 前点在前
2 点在 3 点的西偏北 20°3-2 = 290°“在” → 后点在前
H 点（起飞点）位于 4 点 SE 偏 E 10°4-H = 125°从 4 点看 H
5 点相对于 6 点的方位角为 NW 偏 W 5°6-5 = 310°从 6 点看 5 点
3 到 1 的指向角度为 160°3-1 = 160°旋转时用 1-3 = 340°

2.5 方位词速查

八方位：北 0 · 东北 45 · 东 90 · 东南 135 · 南 180 · 西南 225 · 西 270 · 西北 315

十六方位（每档 22.5°）：N 0 · NNE 22.5 · NE 45 · ENE 67.5 · E 90 · ESE 112.5 · SE 135 · SSE 157.5 · S 180 · SSW 202.5 · SW 225 · WSW 247.5 · W 270 · WNW 292.5 · NW 315 · NNW 337.5

2.6 夹角公式

本质：∠HAB 由 A-H 与 A-B 两条边构成，已知一条，求另一条。

待求航向 = 已知航向 ± 夹角度数　（已知 → 待求 顺时针取 +，逆时针取 −）
  • 已知给的是 B-A 或 H-A，先算反方向得到 A-B / A-H。
  • 夹角最大 180°，算出超过 180° 说明取反了：用 360° 相减。
例已知 2-H = 135°，且 ∠H23 中从 2-H 到 2-3 是顺时针 110° → 2-3 = 135 + 110 = 245°。

2.7 顺 / 逆时针怎么判

航线至少 3 个航点才有顺逆概念。做法：由 1 到 2 做延长线并画箭头，看 3 号点在箭头左侧还是右侧。

3 点在左侧
逆时针
夹角法画 2-3 时输入内角要带 负号 −
3 点在右侧
顺时针
夹角法输入内角用 正号 +（直接填正数）

2.8 正多边形内角

内角和 = (N − 2) × 180°　→　每个内角 = (N − 2) × 180° ÷ N
边数 N345681012
内角60°90°108°120°135°144°150°
顺时针+++++++
逆时针−−−−−−−

画法：先画 1-2 边（方位角尽量和题图一致），编辑器切“夹角”模式输入内角 → 反复点生成，直到最后一个点与 1 号点重合（航线闭合）。

2.9 时针分针

时针 = 30°×H + 0.5°×M　｜　分针 = 6°×M　｜　夹角 = |分针 − 时针|（>180° 用 360° 减）
  • 时针 60 分钟走 30° → 0.5°/分；分针 60 分钟走 360° → 6°/分。
  • 题面说“航向 / 方向为 X 点 Y 分” → 直接取时针位置 = 30X + 0.5Y。
  • 题面说“X 点 Y 分时针与分针的夹角” → 求夹角值，再当夹角条件用。
例2:30 → 时针 75°，分针 180°，夹角 105°。1:48 → 时针 54°，分针 288°，差 234° → 360−234 = 126°。

2.10 几何速算（算边长用）

勾股定理a² + b² = c²；3-4-5、5-12-13、6-8-10 常见整数解
45° 等腰直角斜边 = 直角边 × 1.414；两直角边相等
30°-60°-90°三边比 1 : √3 : 2
正弦定理a / sinA = b / sinB = c / sinC（已知两角一边，或两边一对角求方位）
余弦定理c² = a² + b² − 2ab·cosC（已知两边夹角求第三边）
正六边形边长 = 中心到顶点距离 = 外接圆半径；对角线 √3 × 边长

考试现场用计算器（手机科学计算器即可），三角函数要切到 Deg（角度制）。

2.11 坐标轴转换

题卡给的图若带坐标轴（X/Y 箭头），先把图上的轴方向翻译成“北”：图上向上为北 = 0°，然后按箭头方向数出每条边相对“上”的顺时针角。例：图内 X 轴向上、Y 轴向右，则一条沿 X 正方向的边 = 0°，沿 Y 正方向 = 90°，反向 = 180°。

易错“假设方位角”画的图（随便给的 1-2 朝向）不能用真实方位角去定位 H。必须先旋转成真实朝向，再摆 H。

03预规划 SOP（照做就行）

顺序不能乱：画图 → 旋转 → 插避让点 → 摆 H → 平移经纬度 → 录参数 → 检查 → 上传。乱一步就要重来。

  1. 审题（1 分钟） 圈出四样东西：① 图形是什么、几条边、边长/内角；② 顺时针还是逆时针、1 号点在哪个角；③ 朝向条件（哪条边被固定）；④ 参数是“整条航线”还是“某个点”的，循环几圈，哪个点给了经纬度、有没有正负号。
  2. 撒两个点 随便点一个 H，随便点一个 1 号点。位置不用管，最后都会平移/重摆。
  3. 画闭合图形 打开相对坐标编辑器：选基准点 + 插入序号，填方位角 + 距离 → 点生成；或用夹角模式填内角（逆时针带负号）反复生成，直到最后一点与 1 号点重合。
    要交叉/不连续的图形（如蝴蝶形）：用距离 0 插入一个与上一点重合的点，再右键调顺序。
  4. 旋转到正确朝向 由条件算出某条边（通常 1-2）的真实方位角 → 用旋转工具输入该方位角 → 确认。图形形状不变，整体转动。
  5. （有避让点才做）插入绕飞点 以 1 号点为基准，按“最后一段飞行的反方向 + 该段距离”插入新点 → 原 1 号变 2 号，新点成为 1 号（避让点）。该点高度单独设成题给的避让高度。
  6. 摆起飞点 H 选中 H，用面板里的快捷调整：起飞点位于第 N 个航点、距离、角度 → 等价于输入 N-H 的方位角 + 距离。
    所有 H 条件最终都要化成“N-H 方位角 + 距离”再填。
  7. 平移经纬度 右侧平移工具：基准点选题里给坐标的那个点 → 填纬度/经度 → 平移。若前面插了避让点，基准点要选 2 号点（题卡上的“图形 1 号点”已经是你的 2 号点）。
  8. 录参数 左侧航点面板：高度、水平速度、到达速度、垂直速度、悬停时间、机头指向；全局项在航线设置里改：整体高度、循环模式、转弯模式、完成动作。逐点必改，别只改一个点。
  9. 检查 + 上传（3 分钟） 用测距工具或图上的航段标签抽检方位角/距离 → 对照题卡逐条核 → 上传 → 设置开始执行点。

04题型 · 旋转条件（决定图形朝向）

题卡里“航向（或位置要求）”那一条，作用只有一个：算出某条边的真实方位角，然后用旋转工具转过去。

题面写法换算动作
① 直接给一条边
“3 到 1 的指向角度为 160°”
“3 点到 2 点 215° 方向”		 3-1 = 160° → 若要 1-3，用1-3 = 340°
3-2 = 215° → 2-3 = 35°		 把这条边转到该方位角
② 点在方向 + 距离
“4 点在 3 点 NE 方向 140 米处”		 3-4 = 45°（顺带核对边长 140m） 旋转到 45°
③ 夹角（单）
“∠H31=30°（起飞点在图形内侧）”
“∠H12=30°”		 先算 H-1 / H-3 或 1-H，再 待求 = 已知 ± 30° 旋转 + 用同一条条件摆 H
④ 双夹角
“∠H12=30°，∠H14=120°”		 两个角都基于同一条已知边 → 分别加减，得到两条边方位角 先旋转，再摆 H（两射线交会）
⑤ 航向异同
“2-3 与 H-1 航向相同 / 相反（相向）”		 相同 → 2-3 = H-1
相反 → 2-3 = H-1 ± 180°		 算出 2-3 后旋转
⑥ 风向（15%）
“西北风，2-3 为逆风”“5 到 4 正右侧风”
“3 位于 2 点正下风”		 风向 F = 风的来向（西北风 F=315°）
顺风 = F + 180　逆风 = F
左侧风 = F + 90　右侧风 = F − 90
正下风 = 顺风 = F+180；正上风 = 逆风 = F		 得出该边方位角后旋转
⑦ 钟点 / 时针分针
“A-B 航向为 3 点 20 分（时针）”
“2 点 30 分时针与分针的夹角”		 “航向为 X 点 Y 分” → 30X + 0.5Y
“夹角” → 先算夹角值，再当③用		 得出方位角后旋转
⑧ 图形理解
“H 到 5、6 距离相等且等于边长”
“H 平分 ∠612”“H 在图形中心”
“该边中点”“垂直于某边”		 用几何关系推出角度：等边→60°，等腰直角→45°/90°，正方形→45° 对角线，中心/角平分→减半 推出的角度当①②③用
⑨ 坐标轴
图上带 X / Y 箭头		 “向上为北”读角度：沿 X 正方向、沿 Y 正方向各是多少度 读出某边方位角后旋转
⑩ 双航点坐标
A、B 两点经纬度		 用坐标画出 A、B → 图上读 A-B 的方位角与距离 → 这个方位角就是真实朝向 不需要旋转，直接按 A-B 画图
⑪ 逆时针图形 夹角法输入内角时全部加负号 画图阶段处理，不影响旋转

05题型 · 起飞点 H 条件

两条铁律：全部化成“N-H 方位角 + 距离”；凡是“起飞点到 X 点”，都要先取反方向。

题面写法换算成 N-H备注
① 起飞点到 X 点航向 SW，距离 80m 题给 H-X = 225°
要填 X-H = 45°		 反向 180°
② 起飞点位于 X 点西偏北 20°，距离 200m 题给 X-H = 290°，直接填 “位于 X 点”= 从 X 看 H
③ ∠H12=30°，∠H14=120°，距 1 点 75m 以 1 号为基准：1-H = 1-2 ± 30°，还要满足 1-H = 1-4 ± 120°，两射线交会；距离 75m 两角同时满足才唯一
④ ∠H31=30°（起飞点在图形内侧） 先 1-3 = 3-1 + 180，再 1-H = 1-3 ± 30° 内侧/外侧决定 + 还是 −
⑤ H-1 与 1-2 同向 / 反向 同向：H-1 = 1-2 → 1-H = 1-2 ± 180
反向：H-1 = 1-2 ± 180 → 1-H = 1-2		 相向 = 相反
⑥ 起飞点到 1、2 两点距离相等 H 在 1-2 的垂直平分线上：中点为基准，沿 1-2 ± 90° 方向，距离 √(D² − (L/2)²) 两个解，按内外侧选
⑦ 起飞点垂直于 1-2 边中点，距离 100m 中点 + 1-2 ± 90° + 100m（朝图形外侧） 先算中点
⑧ 起飞点在 1-2 延长线上，距 1 点 150m 方位角同 1-2，距离 150m 注意是“延长”不是反向
⑨ 双坐标：另给 H 的经纬度 选中 H → 直接输入经纬度 → 回车生效 不要点下面的确认按钮（会按上次条件改 H）
⑩ “起飞点与考试席位的相对方位由委任代表现场决定” 考官现场口述方位+距离，按口述输入 先随便放，最后按口述调
面板用法选中 H 后，快捷调整框有三格：起飞点位于图形的第 [N] 个航点 + 距离 + 角度。这个“角度”就是 N-H 的方位角——所以上面所有换算，最终都填这三个格。

一个完整核对示例

题：等边三角形边长 80m，起飞点到 2 点航向 NE、距离 80m，3 到 1 的指向角 160°。
1）画等边三角形（内角 60°，顺时针 +）→ 闭合。
2）旋转条件：3-1 = 160° → 1-3 = 340°，把 1-3 边转到 340°。
3）H 条件：H-2 = 45° → 要填 2-H = 225°，距离 80m。
4）平移题给经纬度 → 参数 → 测距抽检 2-H = 225° / 80m。

06题型 · 特殊任务

这几种题在常规流程上“插一段”或“换一套条件”，其余步骤不变。

6.1 避让点 / 空域限制（13%）

题面长这样：“由于空域限制：起飞后需先向 NE 方向飞 600m 到达'避让点'，再执行任务航线；避让点高度 320m；图形 1 号点在避让点 NW 方向 500m 处。”

  1. 正常画图 + 旋转先按图形条件把航线画对、转正。
  2. 以 1 号点反推新 1 号点用编辑器以 1 号为基准插入 1 号点：方位角 = 起飞后最后一段飞行的反方向，距离 = 该段长度 → 新点成为 1 号（避让点），原 1 号自动变 2 号。
  3. 两段飞行就做两次“先向 NE 飞 300 到障碍点，再向 NW 飞 500 到航点 1” → 先以 1 号为基准 SE 500 插点（障碍点）；再以障碍点为基准、按障碍点到 H 的关系摆 H（此处 1-H = 225°，300m）。
  4. 单独设避让点高度避让点高度照样例单独改（例：320m）。
  5. 平移基准点换成 2 号点题卡上说的“图形 1 号点”已经是你的 2 号点。
题卡里的叫法对应你航线里的航点
“避让点” / “过渡点” / “障碍点”（第一个点）1 号点
“题卡图形 1 号点” / “图形的第 1 点”2 号点（序号全部 +1）
平移经纬度的基准点2 号点

6.2 双坐标（H 坐标 + 航点坐标）

题面不再给“H 与某点的方位角+距离”，而是直接给 H 的经纬度 和 某个航点的经纬度。

  1. 画图 + 旋转常规操作。
  2. 用航点坐标平移平移工具，基准点选那个航点，填经纬度 → 平移。
  3. 直接输 H 坐标选中 H，在上方经纬度框填值 → 按回车生效。
致命操作输完 H 坐标别点下面的确认按钮——那会用上次输入的旧条件改 H，位置立刻错。

6.3 双航点坐标（两个航点坐标，没有 H 位置条件）

  1. 任意点 H、任意点 1先有图面。
  2. 用 A 点坐标平移若 A、B 里有 1 号点就用 1 号点；这样 A 点落到真实位置。
  3. 用 B 点坐标插 B 点打开编辑器上方的坐标开关，填 B 的经纬度插入 → 图上出现 A-B 连线。
  4. 读 A-B 的方位角和距离这就是真实朝向和边长 → 关掉坐标开关 → 按这个方位角/距离把其余点画完。
  5. 不用旋转此时图形已经是正确朝向，直接摆 H、平移、参数。
致命操作坐标开关不关就继续加点 → 所有点都按坐标插入，全部与 1 号点重合，图形毁掉。

6.4 扫描航线（9%，新题必看）

题面：“（一）规划扫描航线，要求闭合不循环，航线长度为 a，航线间隔为 b，航线相对地面高度为 c，水平速度为 d，垂直速度为 e，转弯模式为协调转弯；（二）a=500m，b=100m，c=300m，d=3m/s，e=2m/s。”

  • “于起飞点前规划”：指图形/扫描区在起飞点前方，按 H 条件摆好后自然满足，不产生额外操作。

09应急返航（手动飞回指定点）

“应急返航”= 回到起飞点 H。考官会让你手动飞向某个航点，考核你的定向能力。

9.1 钟点法：目标方位 = 30° × 钟点数

把“当前机位 → 目标点”连一条线，看它指向几点钟 → 需要的方位角 = 30° × X
钟点123456789101112
方位角3060901201501802102402703003300

9.2 操作序列

  1. 算目标方位 Y确认飞机当前位置到目标点的连线指向 X 点钟 → Y = 30X。再看从现在机头朝向转到 Y，顺时针近还是逆时针近，选近的那边转。
  2. 切姿态模式考官会遮屏/移屏（不许看屏幕飞）。切姿态模式，眼睛看飞机。
  3. 快速转 → 提前减速转先快速转；离 Y 还差 30° 时开始慢转；差 15° 时开始缓慢推前进并继续转到 Y。
  4. 按限速前进考官要求“水平速度不超过 5m/s”就压在 5 以内；角度偏了随时修正方向。
  5. 接近减速接近目标点前减速到 1m/s，让飞机箭头停在目标点上。
  6. 风大怎么修有侧风会飘，用副翼持续修正，保持朝目标点飞。
顺 / 逆判断
顺时针 = 右转（副翼/方向杆向右），逆时针 = 左转。差值 ≤ 180° 的那边就是更快的方向。
扣分点
方位角转过（过冲）、速度超限、箭头没停在点上、切错模式。宁可慢转，不要过冲。
